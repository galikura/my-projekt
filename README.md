## Обо мне

Я **Galikura**, развиваюсь в направлении **Vibe Coding Development** и планирую создавать отдельные цифровые продукты — от лендингов и корпоративных сайтов до CRM-систем и инструментов автоматизации.

Мне интересен не только внешний интерфейс, но и весь путь, который проходит бизнес-процесс: как посетитель оставляет заявку, как менеджер получает её в CRM, как меняется статус заказа и как руководитель видит результат в аналитике.

Сейчас мои продукты находятся **на этапе идей и проектирования**. В этом профиле я буду публиковать реальные прототипы, демонстрации, исходный код и заметки о разработке по мере их появления.

> **Моя цель** — создавать понятные инструменты, которые уменьшают объём рутинной работы и помогают людям сосредоточиться на действительно важных задачах.

### Что для меня означает вайбкодинг

Вайбкодинг — это способ быстрее переходить от идеи к работающему прототипу, используя ИИ как помощника в проектировании, написании и объяснении кода. При этом качество продукта по-прежнему зависит от постановки задачи, проверки результата, тестирования и ответственности разработчика.

## Направления продуктов

Планирую развивать несколько самостоятельных направлений. Их можно использовать по отдельности или постепенно объединять в единую систему.

| Направление | Что можно реализовать | Какую задачу решает |
| --- | --- | --- |
| **Лендинги** | Презентация продукта или услуги, формы заявок, адаптивный интерфейс | Помогает понятно представить предложение и получить обращение клиента |
| **Корпоративные сайты** | Каталоги, страницы услуг, личные кабинеты, интеграции с внутренними сервисами | Объединяет информацию о компании и точки взаимодействия с клиентами |
| **CRM-системы** | База клиентов, сделки, статусы, история коммуникаций, роли сотрудников | Систематизирует работу с клиентами и снижает риск потерять важную информацию |
| **Управление заказами** | Создание заказа, этапы обработки, ответственные, сроки, комментарии | Делает выполнение заказа прозрачным для команды и клиента |
| **Аналитика** | Дашборды, ключевые показатели, фильтры и отчёты | Помогает видеть текущее состояние процессов и принимать решения на основе данных |
| **Уведомления** | Сообщения в Telegram и по email, напоминания о событиях и изменениях статусов | Своевременно информирует участников процесса |
| **Интеграции и автоматизация** | Передача заявок между сервисами, автоматические сценарии, повторяющиеся операции | Уменьшает ручной ввод данных и количество рутинных действий |

### Возможный путь клиента в единой системе

```text
Сайт или лендинг
       ↓
Форма и новая заявка
       ↓
Клиент и заказ в CRM
       ↓
Обработка, статусы и уведомления
       ↓
Аналитика и отчёты
```

Такой сценарий может стать основой одного из первых прототипов: начать с простой формы и постепенно развивать её до полноценного рабочего инструмента.

## Подход к разработке

1. **Сначала задача, затем технологии.** До начала разработки важно понять, кто будет пользоваться продуктом, какие действия он выполняет и какой результат считается полезным.
2. **Небольшие итерации.** Начинать с минимально работающей версии, проверять её и добавлять функциональность по мере необходимости.
3. **Понятный интерфейс.** Убирать лишние шаги, использовать ясные названия и делать состояние системы видимым для пользователя.
4. **Осмысленная работа с ИИ.** Использовать AI-инструменты для прототипирования, поиска вариантов решения и разбора ошибок, но не принимать сгенерированный код без проверки.
5. **Качество и безопасность.** Проверять основные сценарии, валидировать данные, предусматривать разграничение доступа и не публиковать секретные ключи.
6. **Документация.** Описывать запуск, архитектуру и ограничения проекта так, чтобы его можно было понять и развивать дальше.

## Технологический стек

Это **ориентировочный стек для обучения и первых продуктов**, а не перечень подтверждённого production-опыта. Конкретный выбор будет зависеть от задачи, но стартовый набор должен оставаться достаточно компактным.

| Область | Технологии и инструменты | Назначение |
| --- | --- | --- |
| **Frontend** | TypeScript, React, Next.js, Tailwind CSS | Интерфейсы, лендинги, личные кабинеты и CRM-панели |
| **Backend и данные** | Node.js, Supabase, PostgreSQL | Серверная логика, хранение данных, авторизация и API |
| **Интеграции** | REST API, Telegram Bot API, email-сервисы | Обмен данными, заявки и уведомления |
| **Разработка и публикация** | Git, GitHub, Vercel | Контроль версий, совместная работа и развёртывание |
| **Качество кода** | ESLint, Prettier, Playwright | Единый стиль, статические проверки и тестирование сценариев |
| **AI-инструменты** | Cursor, GitHub Copilot, ChatGPT | Проектирование, прототипирование, объяснение кода и документация |

**Базовая связка для первых проектов:** `TypeScript + Next.js + Supabase + GitHub`. Она позволяет развивать frontend, backend и базу данных в рамках одного понятного стека, не распределяя внимание между слишком большим количеством технологий.
